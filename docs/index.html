1. 适用范围与角色

本政策适用于名为 Clipora 的移动应用程序（当前以 iOS 为主）及其相关说明页面。 「我们」指 Clipora 的开发 / 运营方；「你」指使用本 App 的用户。

Clipora 的产品定位是私人百宝箱 / 收纳箱：你可以把链接、图文、视频、笔记， 或只是想写下的情绪与念头收进来，按目录整理，需要时再打开，也可以听书。

使用 Clipora，即表示你已阅读本政策。若你不同意，请停止使用本 App。

2. 我们收集 / 处理哪些信息

2.1 默认保存在本机的内容（由你创建）

下列信息主要用于实现收纳与回看功能，默认保存在你的设备上：

  • 你投递或剪藏的链接、网页标题与正文、封面与媒体资源
  • 你导入或拍摄的图片、视频，以及你主动「钉住离线」下载到本地的文件
  • 笔记、日记、目录 / 文件夹结构、堆放等整理信息
  • 听书相关偏好（例如退出文章后是否继续听、语速、声源选择）
  • 视频播放进度等使用状态
  • 本机 OCR（如系统 Vision）识别出的图片文字，用于本地搜索
  • 引导页是否已看过等界面状态

2.2 你主动提供的联系信息

当你通过「意见反馈」发送邮件时，邮件内容、发件邮箱以及你填写的问题描述会进入你所使用的邮件服务， 并到达我们用于支持的邮箱（当前为 644926119@qq.com）。 我们仅将此类信息用于回应反馈、排查问题与改进产品。

2.3 我们不主动收集的信息

  • 不强制注册账号，因此通常不收集姓名、手机号、社交账号等注册资料
  • 不做跨 App 广告追踪 ID 用于营销画像（若未来引入需单独说明并按系统要求申请授权）
  • 不会在后台持续上传你的整库剪藏内容到我们自建服务器做内容分析（当前以本机存储为主）

3. 系统权限说明

仅在功能需要时请求，你可以在系统设置中随时关闭；关闭后对应功能可能不可用：

  • 剪贴板：在你打开 / 回到 App 时读取，用于识别可收纳的链接或媒体。不会在 App 未使用时后台持续读取。
  • 照片图库：导入媒体到资料库，或将内容保存到系统相册（含批量保存等 Pro 能力）。
  • 相机：仅在你主动拍摄照片 / 视频时使用。
  • 麦克风：录制语音笔记或拍摄视频时收录声音。
  • 语音识别：将语音转为文字输入时使用（可能调用系统语音服务）。
  • 网络：抓取你主动投递的网页 / 平台内容、刷新过期媒体地址、完成购买相关校验。
  • 后台音频：听书时在离开文章页后继续朗读。

4. 信息如何使用

  • 提供、维护与改进剪藏、整理、阅读、听书、搜索、离线钉住等功能
  • 处理 App 内购买与恢复购买（通过 Apple）
  • 回应你的反馈与支持请求
  • 履行法律法规要求或应对有效的法律程序

5. 存储位置、期限与删除

  • 本机数据：保存在你的设备（及你开启的系统备份，如 iCloud 设备备份，由 Apple 管理）。
  • 期限：本机内容在你保留 App 数据期间一直存在；你可自行删除单条内容、清空回收站或卸载 App。
  • 卸载：卸载 App 后，App 沙盒内数据通常会被系统删除；已保存到系统相册的文件不会因卸载而自动删除。
  • 反馈邮件：我们会在处理完毕后按合理期限保留或删除，除非法律要求更长保存。

6. 第三方服务

  • Apple：分发、系统服务、App 内购买、家庭共享、部分语音 / 安全能力等。 适用 Apple 隐私政策 与媒体服务条款。
  • 内容来源网站（如你投递的网页、小红书、知乎、B 站等）： App 会向这些站点请求页面或媒体。其日志、Cookie、地区限制等由其自行控制，请参阅各站隐私政策。
  • 邮件服务商：当你发送反馈邮件时，传输与存储受你与邮件服务商协议约束。

我们要求自身仅在实现功能所必需的范围内与第三方交互，但无法控制第三方的独立处理行为。

7. 订阅与支付

Clipora Pro（如月订阅 / 年订阅）通过 Apple App 内购买完成。 支付卡信息、账单地址等由 Apple 处理，我们无法读取完整支付卡号。 管理或取消订阅请在系统「设置 → Apple ID → 订阅」中操作。

使用条款（许可协议）采用 Apple 标准 Licensed Application EULA。

8. 我们不会做什么

  • 不会出售你的个人数据
  • 不会把你的剪藏内容用于第三方广告定向
  • 不会在未说明且未经适当机制的情况下，把完整本地收纳库上传到我们自有服务器做营销分析

9. 安全措施

我们采取合理的技术与管理措施保护本机与沟通渠道中的信息，例如使用系统沙盒存储、HTTPS 访问网络资源等。 但任何互联网或设备存储都无法保证绝对安全，请妥善保管设备解锁方式，并注意公共网络风险。

10. 儿童隐私

Clipora 面向一般用户，不以 13 周岁以下儿童为主要服务对象，也不会故意收集儿童的个人信息。 若你是监护人并认为儿童向我们提供了信息，请联系我们，我们会尽快核实并处理。

11. 跨境与适用法律

本机数据通常留在你的设备所在地。当你访问境外网站或使用 Apple 全球服务时，相关数据可能按各服务商的规则处理。 本政策的解释与争议，在不与强制法冲突的前提下，优先适用你下载 App 时所在地区的相关法律及 Apple 平台规则。

12. 你的选择与权利

  • 在系统设置中管理相册、相机、麦克风、语音识别等权限
  • 在 App 内删除内容、管理目录，或卸载 App 以清除沙盒数据
  • 在 Apple 订阅页管理 / 取消 Pro 订阅
  • 就隐私问题发邮件联系我们（见下文）；在适用法律下，你可能享有查阅、更正、删除等权利

13. 政策更新

我们可能适时更新本政策（例如功能或法规变化）。更新后会修改本页「更新日期」。 重大变更时，我们也可能通过 App 内说明或其他合理方式提示。更新后继续使用即表示你了解更新内容。
